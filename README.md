## 2. Funcionalidades Principales
* Interfaz nativa desarrollada con Jetpack Compose.
* Sistema de caché local para optimización de red mediante OkHttp/Retrofit.
* Operaciones CRUD en tiempo real sincronizadas con backend propio.
* Integración de datos de terceros sin impacto en los servicios locales.
* Soporte multi-idioma (Internacionalización).
